# Quickstart

<p className="lede">
  Five steps. Five minutes. Devnet only. By the end you'll have a deployed program funded by the protocol and you'll know how to repay to claim authority.
</p>

<Callout kind="tldr">
  **tl;dr —** Install the CLI → `solignition init` → fund your devnet wallet → `solignition deploy --file my_program.so` → `solignition repay <LOAN_ID>`.
</Callout>

## Prerequisites

- **Solana CLI installed.** `solana --version` should print something.
- **A devnet keypair.** `solana-keygen new -o ~/.config/solana/id.json` if you don't have one.
- **~1 SOL on devnet** to cover transaction fees and the admin fee. Airdrop with `solana airdrop 2 --url https://api.devnet.solana.com`.
- **A compiled `.so`** at `target/deploy/*.so`. Any Anchor or native BPF program works.

If you haven't installed the CLI yet, do that first: [Install the CLI](/get-started/cli-install).

## 1. Initialize the CLI

```bash
solignition init
```

Interactive wizard. Default answers are fine for devnet — just press Enter through:

- `api_url` → `https://api.solignition.ngrok.app` (current devnet deployer endpoint)
- `rpc_url` → `https://api.devnet.solana.com`
- `keypair_path` → `~/.config/solana/id.json`
- `program_id` → `HVzpjSxwECnb6uY9Jnia48oJp4xrQiz5jgc5hZC5df63`

Config gets written to `~/.solignition/config.toml`. See [Install the CLI](/get-started/cli-install) for env var overrides.

## 2. Check your wallet

```bash
solignition wallet
# Address: <your pubkey>
# Balance: 2.0 SOL (devnet)
```

If the balance is low, airdrop more:

```bash
solana airdrop 2 --url https://api.devnet.solana.com
```

## 3. Deploy in one command

```bash
solignition deploy --file target/deploy/my_program.so
```

You'll see a confirmation prompt with the estimated loan terms. Confirm with `y` (or pass `-y` to skip).

Expected output:

```
$ solignition deploy --file target/deploy/my_program.so

  ✓ bytecode validated · 247 KB · BPF
  ✓ rent estimated    · 4.20 SOL
  ✓ loan requested    · #148 · 30d · 5.0%
  ✓ pool disbursed    · tx 5xK..pQR
  ✓ deployed          · B4dGz..LmXq

  authority: protocol (escrow) — repay to claim
  next: solignition repay 148
```

The loan ID (`148` here) is what you'll use to repay. Write it down or read it from `solignition loans`.

## 4. Track the deployment

```bash
# Single loan
solignition status 148

# Every loan you've opened
solignition loans
```

`status` shows the current `LoanState`, time remaining, total owed, and the deployed program pubkey.

## 5. Repay to claim authority

```bash
solignition repay 148
```

Confirm with `y`. The CLI debits your wallet for principal + accrued interest. The deployer service then transfers upgrade authority to you within a few seconds.

Verify with the Solana CLI:

```bash
solana program show <PROGRAM_PUBKEY> --url devnet
# Upgrade Authority: <your pubkey>   ← you should see your wallet here after Repaid
```

You now hold standard upgrade authority. You can upgrade, freeze, rotate, or close the program from your wallet like any normal Solana program.

<Callout kind="warn">
  **Don't forget to repay.** If the loan expires unrepaid, the deployer closes the program and reclaims the SOL for LPs. There is no grace period. See [What if I default?](/builders/default) for the full default flow.
</Callout>

## Going to mainnet

Mainnet is pending. When it ships, override the RPC in your config to point at a mainnet endpoint:

```bash
solignition init --rpc-url https://api.mainnet-beta.solana.com
```

The CLI detects mainnet via the genesis hash and inserts an extra confirmation prompt before any signing action. `-y` skips it for automation.
