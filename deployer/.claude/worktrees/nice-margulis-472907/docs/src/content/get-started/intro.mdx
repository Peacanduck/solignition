# Introduction

<p className="lede">
  Solignition is a permissionless lending protocol on Solana that funds program deployments.
  LPs earn yield. Builders ship without fronting SOL. All on-chain.
</p>

<Callout kind="tldr">
  **tl;dr —** Deposit SOL → earn yield. Or, upload a `.so` → get a loan → deploy → repay → keep upgrade authority.
</Callout>

## Why this exists

The median Solana program costs around **3 SOL** just to deploy.
For a developer shipping their first program, that's a real barrier.
For someone iterating on their tenth, it's friction that compounds.

Solignition fronts the SOL through a peer-to-pool mechanism.
You upload bytecode, the protocol deploys it, you repay with interest.
Liquidity providers earn yield. Nothing custodial. Authority transfers on repay.

## Architecture at a glance

## Quick example

From compiled `.so` to deployed program in a single command:

<CodeBlock title="terminal" lang="bash" rawCode={`$ solignition deploy --file target/deploy/my_program.so

  ✓ bytecode validated · 247 KB · BPF
  ✓ rent estimated    · 4.20 SOL
  ✓ loan requested    · #148 · 30d · 5.0%
  ✓ pool disbursed    · tx 5xK..pQR
  ✓ deployed          · B4dGz..LmXq

  authority: protocol (escrow) — repay to claim
  next: solignition repay 148`}>
{`$ solignition deploy --file target/deploy/my_program.so

  ✓ bytecode validated · 247 KB · BPF
  ✓ rent estimated    · 4.20 SOL
  ✓ loan requested    · #148 · 30d · 5.0%
  ✓ pool disbursed    · tx 5xK..pQR
  ✓ deployed          · B4dGz..LmXq

  authority: protocol (escrow) — repay to claim
  next: solignition repay 148`}
</CodeBlock>

<Callout kind="warn">
  **Heads up —** If you don't repay before expiry, the protocol closes the program
  and reclaims SOL to protect LPs. You keep upgrade authority only after a successful repay.
</Callout>
