# On-chain program

<p className="lede">

## Instructions

| Instruction | Signer | Args | Purpose |
|---|---|---|---|
| `initialize` | admin | `admin_fee_split_bps, default_interest_rate_bps, default_admin_fee_bps` | One-time bootstrap. Creates `ProtocolConfig`, vault, authority, admin and treasury PDAs. |
| `update_config` | admin | `admin_fee_split_bps?, default_interest_rate_bps?, default_admin_fee_bps?, deployer?, treasury?, admin?` | Rotate any subset of config fields. All args optional. |
| `set_paused` | admin | `is_paused` | Emergency switch. When paused, deposits / borrows / repays are rejected with `ProtocolPaused`. |
| `deposit` | LP | `amount: u64` | Move SOL from your wallet into the vault. Mints shares to your `DepositorRecord`. |
| `withdraw` | LP | `shares: u64` | Burn shares, receive SOL at the current share ratio. Bounded by idle vault liquidity. |
| `request_loan` | borrower | `principal, duration, interest_rate_bps, admin_fee_bps` | Open a new loan. Admin fee is debited upfront from the borrower's wallet. State starts at `Pending`. |
| `set_deployed_program` | admin | `loan_id, program_pubkey` | Called by admin after the deployer publishes the program. Writes the program pubkey onto the `Loan` and flips state to `Active`. |
| `repay_loan` | borrower | `loan_id` | Pay principal + accrued interest. State → `RepaidPendingTransfer`. |
| `transfer_authority_to_borrower` | deployer | `loan_id` | CPI into BPF Upgradeable Loader. Moves upgrade authority from `authority_pda` to the borrower. State → `Repaid`. |
| `recover_loan` | admin + deployer | _none_ | Run after expiry on unrepaid loans. State → `Recovered`. |
| `return_reclaimed_sol` | deployer | `amount: u64` | Push recovered SOL back to the vault. State → `Reclaimed`. |
| `claim_admin` | admin | _none_ | Withdraw the admin's accumulated share from the `admin_pda` into the treasury. |

For account types those instructions read and write, see [Account types](/reference/accounts).

## Events

Every state-changing instruction emits a typed event via `emit_cpi!`. Listen via `connection.onLogs` or an Anchor `program.addEventListener`.

| Event | Fields | Emitted by |
|---|---|---|
| `ProtocolInitialized` | `admin, treasury` | `initialize` |
| `ConfigUpdated` | `admin_fee_split_bps, default_interest_rate_bps, default_admin_fee_bps` | `update_config` |
| `ProtocolPausedChanged` | `is_paused` | `set_paused` |
| `Deposited` | `depositor, amount, total_shares` | `deposit` |
| `Withdrawn` | `depositor, amount, shares_burned, remaining_shares` | `withdraw` |
| `YieldClaimed` | `depositor, amount, shares_burned, remaining_shares` | (LP yield distribution) |
| `LoanRequested` | `borrower, loan_id, principal, duration, interest_rate_bps, admin_fee` | `request_loan` |
| `LoanDeployed` | `loan_id, program_pubkey` | `set_deployed_program` |
| `LoanRepaid` | `loan_id, total_repaid, interest_paid` | `repay_loan` |
| `AuthorityTransferred` | `program_pubkey, new_authority` | `transfer_authority_to_borrower` |
| `LoanRecovered` | `loan_id, admin_fee_distributed` | `recover_loan` |
| `SolReclaimed` | `loan_id, amount, total_reclaimed` | `return_reclaimed_sol` |

## PDA seeds

All PDAs are derived from the program ID using these seeds. Use `PublicKey.findProgramAddressSync` (web3.js) or `Pubkey::find_program_address` (Rust).

| PDA | Seeds | Purpose |
|---|---|---|
| `ProtocolConfig` | `["config"]` | Singleton config + counters. |
| Vault | `["vault"]` | Holds LP deposits and accrued yield. |
| Authority escrow | `["authority"]` | Holds upgrade authority for active loans. |
| Admin PDA | `["admin"]` | Holds the admin's claimable share until `claim_admin`. |
| Treasury PDA | `["treasury"]` | Protocol revenue. |
| Event authority | `["__event_authority"]` | Anchor-generated, used for `emit_cpi`. |
| `Loan` | `["loan", loan_id, borrower]` | One per loan. |
| `DepositorRecord` | `["depositor", owner]` | One per LP. |
